Cookie Policy

Last updated: 2 November 2026

This company website sets no cookies and does not use browser local storage, advertising pixels, analytics tools or embedded third-party media.

What loads when you visit

Images, icons, CSS and JavaScript are included with the website and served from the same hosting location. Fonts use the system fonts on your device; there are no external font requests.

Hosting and linked services

Delivering a page requires technical request information, such as an IP address. This is separate from browser cookies. When hosted on GitHub Pages, GitHub logs visitors’ IP addresses for security; details appear in our Privacy Policy.

External project links open separate websites. Email and telephone links open your selected application. Those services have their own privacy practices and may use cookies.

Your control

You can manage cookies through your browser settings. This website does not use optional tracking technologies, so there are no tracking preferences to accept or reject.

Future changes

If optional analytics, advertising, embedded media or similar tools are introduced, this policy and any required consent controls must be updated before those tools are enabled.
